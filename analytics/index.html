Understand your traffic and course engagement

Your existing GoatCounter account receives the site's measurements. This page explains the reports and creates tagged links. It does not expose private traffic, require an API key or load a tracking script.

One owner step

Sign in to the private GoatCounter dashboard. The site code is already installed. No new analytics account or tracking ID is needed.

Review the dashboard's pages, referrers, campaigns, locations, browsers, systems, languages and screen-width reports. Collection settings control which breakdowns are available. For personal browsing, open the library with your browser opted out.

Keep the dashboard private. An API token is a secret and must never be pasted into the repository, this page or a public script.

A useful weekly review

  1. Compare the past seven days with the previous seven. Check page visits separately from custom events: adding events changes a combined total.
  2. Review referring domains and campaigns to see which posts bring traffic. Countries, browsers, operating systems and screen widths help you choose where to test the site.
  3. Filter events by a course prefix such as azure/. Compare course opens, numbered-mission reach, active-time thresholds and feature use.
  4. Use azure/track-junior/, track-senior/ or the configured course path to compare navigation within one path. Paths differ in length.
  5. Look for a repeated drop in mission reach, then inspect that mission. The counts are aggregate signals, not a joined visitor-level funnel or proof of a teaching problem.

Event reference

Example eventWhat it means
hub/open-azureA library card for Azure was clicked. Browser opening behavior and request loss can affect the count.
azure/course-openedThe course document opened in this tab session. A page-view hit also records each document load.
azure/course-startedA numbered mission was reached. A map jump or resumed visit can cause this.
azure/path-juniorA chosen or restored path was observed.
azure/mission-03Mission 3 was reached. It does not mean missions 1 and 2 were read.
azure/progress-50The course navigation position reached or passed 50%. This measures position, not the proportion read.
azure/mission-03/progress-75The navigation position in mission 3 reached or passed 75%.
azure/mission-end-03Next was pressed past the final frame of mission 3. It is not verified learning completion.
azure/active-300sAt least five estimated minutes accumulated while the course was visible, focused and recently active in this tab session.
azure/interaction-labA lab control was used. Other categories include quiz, bug, order, decision, challenge hints/solution, interview timer/answer/follow-up/review, code-copy and example SQL run. Results are not collected.
azure/finish-clickedThe final Finish button was clicked, potentially after a map jump. The old azure/finished event is retained with the same explicit limitation.
hub/scroll-50The library's scroll position reached or passed 50%.

Path-specific mission, progress and interaction events also appear under azure/track-junior/… and other configured path IDs. Active time is course-wide. Events are locally deduplicated in a tab until 30 minutes of inactivity; GoatCounter applies its own visit/session rules too. These counts are not identified people or exact session totals.

Build a campaign link

Use a tagged link when you share a post. GoatCounter reports the campaign and source for hits carrying those parameters. To attribute a course landing, link directly to that course. Tags are not automatically carried into later untagged URLs, and this does not reconstruct a source-to-completion journey.

Use short public labels with letters, numbers, dots, underscores or hyphens. Do not use personal information. Each label is limited to 64 characters.

Verification and limits

The tracker respects Do Not Track, Global Privacy Control and the saved opt-out. It avoids local test traffic, strips unapproved query values and referrer details, and keeps lessons usable if the provider is blocked or fails. Tests use intercepted traffic so they do not create fake visits in your account.

Only the account owner can confirm actual incoming traffic and enabled account settings. New event history starts with this deployment; past detailed behavior cannot be reconstructed. Aggregate reports do not establish exact time on site, per-person retention, ordered funnels or learning mastery.
